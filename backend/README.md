# /pocketbase

Pocketbase's binary plus its hooks, migrations and static files go into this folder.

Run `pnpm run install:pocketbase` from the repo root to fetch the pinned binary automatically
(see `docs/decisions/004-continuous-integration.md`). To place one manually instead, download it
from [pocketbase.io](https://pocketbase.io/docs) and add it to this folder named `pocketbase`.

Hooks go into `pb_hooks`.

Migrations go into `pb_migrations`.
